A program that writes one pickup line one AI agent would send to another AI agent, to `/output/entry.txt`. No network, no randomness: two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
